## Purpose

This README documents the code files used to construct the Health Professionals Follow-up Study (HPFS) frailty-index analytic data and run longitudinal analyses of frailty trajectories before and after incident cancer. It explains each source script's purpose and the intended order in which scripts should be run.

This file should be updated whenever a new code file is generated or whenever a code file's role, order, or output changes.

Dataset outputs generated by project code, including `.rds`, `.csv`, and other analytic data files, should be saved to:

`/Users/nemo/Library/CloudStorage/OneDrive-HarvardUniversity/Research/Frailty HPFS/Data`

`/Users/nemo/Library/CloudStorage/OneDrive-HarvardUniversity/Research/Frailty HPFS/Results/cancer`

## Active Run Order

### 1. Data Cleaning and Analytic Dataset Construction

Run scripts in `1_data_cleaning` first. These scripts load HPFS source data, construct frailty-index items, reshape the data, perform logical imputation, compute frailty-index versions, merge covariates and cancer records, and generate time variables needed for cancer trajectory analyses.

1. `1_data_cleaning/0_load_main_questionaires.Rmd`
   - Reads HPFS main questionnaire files from raw questionnaire sources.
   - Establishes questionnaire-cycle source data used in later frailty and covariate processing.

2. `1_data_cleaning/0.1_load_long_data_using_hpfs_functions.R`
   - Loads core HPFS longitudinal data through the internal `hpfs` package.
   - Pulls baseline, follow-up, death, race, anthropometric, smoking, physical activity, and other questionnaire-derived datasets.

3. `1_data_cleaning/0.2_load nutrient function.R`
   - Defines the nutrient-loading function used to assemble nutrition variables.
   - Covers total calories, blank FFQ items, alcohol, dietary cholesterol, and saturated fat across available questionnaire cycles.

4. `1_data_cleaning/1_construct new df.R`
   - Builds the initial longitudinal working dataset from HPFS source data.
   - Defines passthrough variables and questionnaire mappings that feed the frailty-item construction workflow.

5. `1_data_cleaning/2_construct FI items.R`
   - Constructs and scores individual frailty-index deficit items across questionnaire cycles.
   - Produces item-level inputs for later naming, reshaping, imputation, and frailty-index computation.

6. `1_data_cleaning/3_rename vars.R`
   - Standardizes frailty-item variable names across cycles.
   - Applies the `fi_` prefix convention and prepares consistent item names for longitudinal processing.

7. `1_data_cleaning/4_wide to long.R`
   - Converts frailty and questionnaire variables from wide cycle-specific format to long person-cycle format.
   - Adds follow-up participation information needed for repeated-measures analyses.

8. `1_data_cleaning/5_logical imputation.R`
   - Applies logical imputation to frailty deficit items.
   - Handles irreversible disease indicators and distinguishes missingness from unasked or inapplicable questionnaire items.

9. `1_data_cleaning/6_compute FI.R`
   - Computes the longitudinal frailty index from imputed frailty deficit items.
   - Uses cycle-specific denominators so unavailable items do not incorrectly penalize participants.

10. `1_data_cleaning/7.1_smoking vars.R`
    - Merges smoking status and pack-year variables into the longitudinal frailty dataset.
    - Performs merge checks for newly added smoking variables.

11. `1_data_cleaning/7.2_nutrient vars.R`
    - Merges nutrient variables into the imputed longitudinal frailty dataset.
    - Adds calories, saturated fat, dietary cholesterol, blank FFQ item count, and alcohol intake.

12. `1_data_cleaning/7.3_cancer records.R`
    - Reads fixed-width HPFS cancer record files.
    - Prepares cancer diagnosis, cancer type, and cancer-death variables for linkage to frailty data.

13. `1_data_cleaning/7_merge covariate.R`
    - Merges external covariates, death data, race, smoking, and other participant-level or cycle-level variables.
    - Produces the main longitudinal frailty-index dataset with covariates and cancer information for analysis.

14. `1_data_cleaning/8_compute FI without cancer.R`
    - Computes a frailty index excluding cancer-related deficit items.
    - This is the preferred frailty-index outcome when cancer is the exposure, because it avoids circularity.

15. `1_data_cleaning/9_time variables generation.R`
    - Generates age, questionnaire-cycle, death, and cancer-timing variables.
    - Aligns frailty measurements relative to cancer diagnosis and follow-up time for downstream trajectory models.
    - Saves the trajectory-ready derived dataset as `Data/FI_longitudinal_1986_2020_IMPUTED_Cancer_timevars.rds` rather than overwriting the broader cancer analytic dataset.

### 2. Active Cancer Trajectory Analyses

Run scripts in `2_data_analysis` after the cleaned analytic dataset and time variables are available. These are the currently active analysis scripts. Earlier EDA and deprecated matching scripts have been moved to `2_data_analysis/old`.

1. `2_data_analysis/4_age_drawing.Rmd`
   - Creates age-scale stochastic-drawing frailty trajectory analyses before and after cancer diagnosis.
   - Assigns cancer-free controls an index age drawn from eligible cases in the same baseline age bin.

2. `2_data_analysis/4.1_age_drawing_agressive cancer.Rmd`
   - Uses age-scale stochastic drawing to compare frailty trajectories by cancer burden.
   - Focuses on aggressive cancer classifications.

3. `2_data_analysis/4.1_aggressive cancer_drawing_MI.Rmd`
   - Combines stochastic drawing with multiple imputation.
   - Estimates frailty trajectories by aggressive cancer burden while accounting for imputation uncertainty.

4. `2_data_analysis/4.2_age_draw_aggressive cancer_separate.Rmd`
   - Runs separate stochastic drawing analyses on the age scale for aggressive cancer groups.
   - Compares each group with corresponding cancer-free controls.

5. `2_data_analysis/4.3_multiple imputation.Rmd`
   - Runs multiple-imputation-based frailty trajectory analyses.
   - Includes pooled mixed-model estimates where applicable.

6. `2_data_analysis/4.4_prostate cancer.Rmd`
   - Compares frailty trajectories for aggressive versus indolent prostate cancer.
   - Uses longitudinal frailty data and mixed-effects models.

7. `2_data_analysis/4.5_Smoking Cancers.Rmd`
   - Compares frailty trajectories for smoking-related versus non-smoking-related cancers.
   - Uses longitudinal frailty data and mixed-effects models.

8. `2_data_analysis/5.1_age_match_aggressive cancer.Rmd`
   - Runs age-scale risk-set matching for aggressive cancer analyses.
   - Estimates trajectories for matched cancer and control groups.

9. `2_data_analysis/5.2_match_prostate cancer.Rmd`
   - Runs risk-set matching analyses for prostate cancer subgroups.
   - Focuses on aggressive versus indolent prostate cancer trajectory comparisons.
